# Electron Assets

Thu muc chua icon build cho app POS Electron.

Dat file theo dung ten:

```text
icon.ico   # Windows, nen dung 256x256 px
icon.png   # Linux, nen dung 512x512 px
icon.icns  # macOS
```

Neu chi build Windows, toi thieu can `icon.ico`.

Co the tao `icon.ico` tu PNG bang cong cu nhu ConvertICO:

```text
https://convertico.com/
```
